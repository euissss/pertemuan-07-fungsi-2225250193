## Struktur Fungsi
- salam: menampilkan salam berdasarkan nama dan kelas.
- luas_persegi_panjang: mengembalikan hasil perkalian panjang dan lebar.
- jumlah_n: mengembalikan jumlah bilangan dari 1 sampai n.
- statistik: mengembalikan nilai minimum, maksimum, dan rata-rata.
- luas_segitiga: mengembalikan luas segitiga.
- faktorial: mengembalikan hasil faktorial.
- tampilkan_menu: menampilkan pilihan operasi matematika.

## Refleksi
Penggunaan fungsi membuat program lebih terstruktur karena
setiap fungsi memiliki tanggung jawab yang jelas.
Parameter memungkinkan fungsi menerima input berbeda,
sedangkan return memungkinkan hasil perhitungan digunakan
kembali. Pengujian dilakukan untuk memeriksa kebenaran hasil.
